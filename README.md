# ci_task_emp1
Codeigniter task for interview  - Project Management 
CodeIgniter Developer Interview Task
Module 1 — User Authentication
• User Registration (Name, Email, Password, Role → Admin/Employee)
• User Login (Session or JWT)
• Password hashing
• Basic UI using Bootstrap or Tailwind
Module 2 — Project & Task Management
Admin:
• Create Project (Name, Description, Start Date, End Date)
Admin & Employee:
• Create Task (Title, Description, Project, Assigned To, Priority, Status)
• Employee updates task status
• Task comments
Module 3 — Leave Tracker
Employee applies leave with:
• From Date
• To Date
• Reason
Logic requirements:
• No overlapping leaves
• Past dates not allowed
• Weekends excluded from leave count
• Max 2 leaves per month
• Auto-calculate leave days
Module 4 — Dashboard
Dashboard must show:
• Total tasks
• Pending tasks
• Completed tasks
• Priority-based task statistics
• Leaves taken this month
Technical Requirements
• CodeIgniter 3 or CodeIgniter 4
• Proper MVC structure
• Form validation
• REST API for Task module
• Pagination in task listing
• Error handling
• Clean UI using Bootstrap/Tailwind
• Optimized SQL queries
